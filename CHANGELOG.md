# Changelog

## 1.1.0

- Rename the app, executable, tray identity, and data directory to MOONLIGHT.
- Use English by default and add immediate English and Simplified Chinese switching.
- Place the language selector between Save and apply and Hide to tray.
- Simplify the settings page to the schedule, start times, combined Windows theme option, and startup option.
- Apply the combined theme option to both Windows and system-following apps.
- Replace temporary action labels with Switch to light and Switch to dark.
- Remove the introductory card, local-time footer, and parenthetical UI descriptions.
- Preserve the previous schedule and migrate the previous startup registration on upgrade.
- Add a reproducible build, regression tests, and a Windows GitHub Actions workflow.
